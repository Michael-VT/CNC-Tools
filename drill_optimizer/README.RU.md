# PCB Drill Optimizer

**Документация на других языках:** [English](README.md) | [Українська](README.UA.md) | [Português](README.PT.md) | [Deutsch](README.DE.md) | [Français](README.FR.md)

Оптимизирует траекторию сверления для производства печатных плат (PCB) путём минимизации расстояния холостого перемещения станка с ЧПУ. Часть проекта [CNC-Tools](https://github.com/Michael-VT/CNC-Tools).

## Возможности

- **Оптимизация траектории** — алгоритм ближайшего соседа + 2-opt минимизирует непроизводительные перемещения
- **Парсер Excellon** — чтение стандартных сверлильных файлов Excellon NC (.drl, .xln, .exc)
- **Ручной ввод** — ввод координат отверстий и инструментов напрямую
- **Поддержка нескольких инструментов** — группировка отверстий по размеру сверла, оптимизация каждой группы, минимизация смен инструмента
- **Визуализация** — предпросмотр траектории на холсте с цветовой кодировкой инструментов
- **Анимация** — пошаговая анимация траектории сверления
- **Генерация G-code** — стандартный G-code для сверления на ЧПУ (совместим с Grbl, Mach3, LinuxCNC)
- **Редактируемый вывод** — G-code можно редактировать перед сохранением
- **Автономность** — откройте `drill_optimizer.html` в любом браузере, сервер не требуется
- **Python CLI** — инструмент командной строки для пакетной обработки

## Веб-приложение

Откройте `drill_optimizer.html` в браузере. Установка не требуется.

1. **Загрузите файл** — перетащите сверлильный файл Excellon методом drag & drop или нажмите для выбора
2. **Или введите вручную** — добавьте инструменты и отверстия в разделе "Manual Input"
3. **Оптимизируйте** — нажмите "Optimize Path" для вычисления кратчайшего маршрута сверления
4. **Визуализируйте** — переключайте вкладки: Original / Optimized / Comparison / Animation
5. **Сгенерируйте** — задайте параметры сверления и нажмите "Generate G-code"
6. **Редактируйте и сохраните** — отредактируйте G-code в текстовом поле, затем скопируйте или скачайте файл .nc

## Python CLI

```bash
cd python
python run.py ../tests/fixtures/sample_metric.drl --stats

# С пользовательскими параметрами
python run.py input.drl -o output.nc --feed 300 --plunge 80 --depth -1.8 --rpm 8000

# Предпросмотр с matplotlib
python run.py input.drl --preview
```

### Параметры CLI

| Параметр | По умолчанию | Описание |
|----------|--------------|----------|
| `-o, --output` | stdout | Выходной файл G-code |
| `--feed` | 400 | Скорость рабочей подачи (мм/мин) |
| `--plunge` | 100 | Скорость врезания (мм/мин) |
| `--depth` | -2.0 | Глубина сверления (мм) |
| `--safe` | 20 | Безопасная высота отвода (мм) |
| `--rpm` | 10000 | Скорость вращения шпинделя (об/мин) |
| `--iter` | 200 | Количество итераций 2-opt |
| `--time-limit` | 5.0 | Ограничение времени оптимизации (секунды) |
| `--dwell` | выкл | Добавить выдержку в нижней точке сверления |
| `--preview` | выкл | Показать предпросмотр matplotlib |
| `--stats` | выкл | Вывести статистику оптимизации |

## Формат входных данных

Инструмент принимает сверлильные файлы Excellon NC — стандартный формат данных для сверления PCB. Поддерживаемые функции:

- Метрические (`METRIC`) и дюймовые (`INCH`) единицы измерения
- Подавление ведущих (`LZ`) и конечных (`TZ`) нулей
- Определение инструментов: `T01C0.8` (инструмент 1, диаметр 0.8 мм)
- Координаты сверления: `X1000Y2000`
- Пазы: `G85X...Y...X...Y...`
- Автоматическое определение формата координат

## Алгоритм оптимизации

1. **Группировка по инструментам** — отверстия группируются по размеру сверла для минимизации смен инструмента
2. **Ближайший сосед** — жадный алгоритм обходит отверстия каждой группы, начиная с ближайшего
3. **Улучшение 2-opt** — итеративный обмен парами рёбер для устранения пересечений траектории
4. **Упорядочивание групп** — группы инструментов упорядочиваются для минимизации межгрупповых перемещений

## Формат вывода G-code

```
G21                          (Metric)
G90                          (Absolute positioning)
G00 Z20.000                  (Safe height)
T01
M06                          (Tool change)
M03 S10000                   (Spindle on)
G00 X10.000 Y5.000           (Rapid to hole)
G00 Z2.000                   (Approach)
G01 Z-2.000 F100             (Drill)
G00 Z2.000                   (Retract)
...
M05                          (Spindle off)
M30                          (End program)
```
