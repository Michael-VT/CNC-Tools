# PCB Drill Optimizer

Оптимізує траєкторію свердління для виробництва друкованих плат шляхом мінімізації відстані переміщення верстата з ЧПК. Частина проєкту [CNC-Tools](https://github.com/Michael-VT/CNC-Tools).

## Можливості

- **Оптимізація траєкторії** — алгоритм найближчого сусіда + 2-opt мінімізує холості переміщення
- **Парсер Excellon** — зчитує стандартні файли Excellon NC drill (.drl, .xln, .exc)
- **Ручне введення** — введення координат отворів та інструментів вручну
- **Підтримка кількох інструментів** — групування отворів за розміром свердла, оптимізація кожної групи, мінімізація замін інструментів
- **Візуалізація** — попередній перегляд траєкторії на canvas з кольоровим кодуванням інструментів
- **Анімація** — покрокова анімація траєкторії свердління
- **Генерація G-code** — стандартний G-code для свердління з ЧПК (сумісний з Grbl, Mach3, LinuxCNC)
- **Редагований результат** — G-code можна редагувати перед збереженням
- **Автономність** — просто відкрийте `drill_optimizer.html` у будь-якому браузері, сервер не потрібен
- **Python CLI** — інструмент командного рядка для пакетної обробки

## Вебдодаток

Відкрийте `drill_optimizer.html` у браузері. Встановлення не потрібне.

1. **Завантажити файл** — перетягніть Excellon drill file у вікно або натисніть для вибору
2. **Або введіть вручну** — додайте інструменти та отвори у розділі "Manual Input"
3. **Оптимізувати** — натисніть "Optimize Path" для обчислення найкоротшого маршруту свердління
4. **Візуалізувати** — перемикайте вкладки: Original / Optimized / Comparison / Animation
5. **Згенерувати** — встановіть параметри свердління та натисніть "Generate G-code"
6. **Редагувати та зберегти** — відредагуйте G-code у текстовому полі, потім копіюйте або завантажте файл .nc

## Python CLI

```bash
cd python
python run.py ../tests/fixtures/sample_metric.drl --stats

# З custom параметрами
python run.py input.drl -o output.nc --feed 300 --plunge 80 --depth -1.8 --rpm 8000

# Попередній перегляд з matplotlib
python run.py input.drl --preview
```

### Параметри CLI

| Параметр | Значення за замовчуванням | Опис |
|----------|--------------------------|------|
| `-o, --output` | stdout | Файл результату G-code |
| `--feed` | 400 | Швидкість подачі (мм/хв) |
| `--plunge` | 100 | Швидкість врізання (мм/хв) |
| `--depth` | -2.0 | Глибина свердління (мм) |
| `--safe` | 20 | Безпечна висота відводу (мм) |
| `--rpm` | 10000 | Оберти шпинделя (об/хв) |
| `--iter` | 200 | Кількість ітерацій 2-opt |
| `--time-limit` | 5.0 | Ліміт часу оптимізації (секунди) |
| `--dwell` | вимк. | Пауза на дні отвору |
| `--preview` | вимк. | Показати попередній перегляд matplotlib |
| `--stats` | вимк. | Вивести статистику оптимізації |

## Формат вхідних даних

Інструмент приймає файли Excellon NC drill — стандартний формат для даних свердління друкованих плат. Підтримувані можливості:

- Метричні (`METRIC`) та імперські (`INCH`) одиниці
- Подавання нулів: ведуче (`LZ`) та відсікаюче (`TZ`)
- Визначення інструментів: `T01C0.8` (інструмент 1, діаметр 0.8мм)
- Крапки свердління: `X1000Y2000`
- Пази: `G85X...Y...X...Y...`
- Автовизначення формату координат

## Алгоритм оптимізації

1. **Групування за інструментом** — отвори групуються за розміром свердла для мінімізації замін інструментів
2. **Найближчий сусід** — жадібна побудова маршруту відвідує отвори кожної групи, починаючи з найближчого
3. **Покращення 2-opt** — ітеративно обмінює пари ребер для усунення перехресть траєкторії
4. **Впорядкування груп** — групи інструментів впорядковуються для мінімізації переміщень між групами

## Формат результату G-code

```
G21                          (Metric)
G90                          (Absolute positioning)
G00 Z20.000                  (Safe height)
T01
M06                          (Tool change)
M03 S10000                   (Spindle on)
G00 X10.000 Y5.000           (Rapid to hole)
G00 Z2.000                   (Approach)
G01 Z-2.000 F100             (Drill)
G00 Z2.000                   (Retract)
...
M05                          (Spindle off)
M30                          (End program)
```
